# 构建环境

## 一、CI 用的（GitHub Actions）

`release.yml` 里已经写死，不用你操心：

- `actions/setup-java@v4`，Temurin **JDK 17**
- `android-actions/setup-android@v3`
- `sdkmanager` 装 `platforms;android-34` + `build-tools;34.0.0`
- Gradle 由底座仓库自带的 `gradlew` 提供（wrapper 会自己下）

## 三、签名

签名密钥**不进仓库**（`.gitignore` 已排除 `keystore/*.jks`），只放三处：

1. 本地：`keystore/release.jks`（离线备份 U 盘 + 网盘各一份）
2. CI：四个仓库 Secret — `KEYSTORE_B64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD`
3. 旧版本兼容：4.00.x 时期用的是 `legado-签名.jks`（`CN=Reader Fanqie Style`），
   **如果要对 4.00.x 老用户做覆盖升级，必须继续用同一把钥匙**，
   所以本仓库正式发版也沿用它，见 `keystore/README.md`。

生成 base64：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes('keystore\release.jks')) | Set-Clipboard
```

然后到仓库 Settings → Secrets and variables → Actions 里粘贴。

## 四、网络

本机 `github.com` 偶发不可达（`SEC_E_NO_CREDENTIALS` / 被 hosts 屏蔽）。
`scripts/prepare-base.js` 按顺序试三个源，前一个失败自动换下一个：

1. `LEGADO_MIRROR` 环境变量（可临时指到自己的镜像）
2. `https://github.com/gedoor/legado.git`
3. `https://gitee.com/mirrors_gedoor/legado.git`

两个都拉不动时，把 `gradle/base-source.json` 的 `repo` 改成任一个能通的镜像即可。

## 五、已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| `SDK location not found` | 没有 `local.properties` | 在底座目录建 `local.properties`，写 `sdk.dir=...`（CI 里由 setup-android 自动处理） |
| `Unsupported class file major version` | JDK 版本不对 | 必须 17；21 会触发 AGP 与 Kotlin 的兼容问题 |
| 覆盖安装提示「应用未安装」 | 签名不同 或 versionCode 变小 | 用同一把钥匙；`versionCode` 只能增 |
| `mergeReleaseResources` 失败 | 内置 assets 文件名与上游冲突 | `apply-patches.js` 已把两个 json 改名成上游认的名字 |
| Gradle 下载慢 | 没走镜像 | 在 `~/.gradle/init.gradle` 配阿里云 maven 镜像 |
